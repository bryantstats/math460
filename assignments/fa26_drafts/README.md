## What is in each folder

- `assignmentN.qmd`: the handout, in the style of `assignment_kaggle.qmd` (overview, what to submit, the problems, AI policy).
- `assignmentN_student.ipynb`: the notebook students fill in (`# TODO` cells and empty **Your answer** cells).
- The solution notebooks (completed, run, with answer keys) and the scripts that build all notebooks are **not in this repo**. They are in `Dropbox/teaching-private/math460_fa26/` (`solutions/` and `build_scripts/`). `.gitignore` blocks `*_solution.ipynb` from being committed here.

## Notes for review

- **Every solution notebook was run end to end**, and the answer keys quote the actual output. Numbers can shift slightly with other library versions.
- **Shared data and splits.** Assignments 8, 9 and 12 use the same breast cancer split (70/30, `random_state=1`, stratified), and 8 and 12 use the same NBA split, so students can compare models across assignments.
- **Assignment 11** needs `torchvision`, which is not in your Anaconda base environment. Colab is the easy option for students. The solution's Part B uses the cats/dogs images in `python/images_recognition/train images`. 235 of those 262 files are `.jfif`, which torchvision skips by default; the notebook handles that.
- **Assignment 13:** some titles in `books_rating.csv` contain HTML entities (e.g. `Angels &amp; Demons`).
- **LLM series (14–16).** One model is carried through all three stages. A14 builds and pre-trains a 477K-parameter character-level GPT on TinyStories (context 128; about 8–15 min on a laptop CPU) and saves `base_model.pt`. A15 fine-tunes it on "Topic: dog / Story: …" examples (10 topics) and saves `instruct_model.pt`. A16 runs DPO with an automatic judge ("is the story about the topic?").
  - `tiny_gpt.py` (in the A15 and A16 folders) holds the same model as A14, plus helpers, so students can load the checkpoints.
  - **Provided checkpoints**, so a failed run doesn't block the next assignment: `a15_.../base_model.pt` (from the A14 solution) and `a16_.../instruct_model.pt` (from the A15 solution). Students also need `tinystories.txt` from A14 (a copy is in each folder).
  - **Design changes after testing:** a "use this word" instruction got 0% (a model this small can't learn to copy an arbitrary word), so A15 uses a fixed set of 10 topics. Training on random windows without masking the prompt reached only about 17% on-topic; whole examples with the loss on the response only reached about 58%. Masking is now the core TODO of A15.
  - Fine-tuning causes large catastrophic forgetting: loss on plain stories rises from about 1.0 to 1.9. A15 Question 6 makes that a discussion point.
- **Workload.** That is 9 assignments, and roughly 7 weeks remain. Natural ways to trim: merge 10 and 11 into one deep-learning assignment; make 16 extra credit; or drop Part B of 13.
