# **How Text Becomes Numbers in NLP**
### Tokenization • IDs • Embeddings • Context Windows
---

# **Why Convert Text to Numbers?**

- Neural networks operate only on **numbers**
- Text is **symbolic**
- Must be encoded numerically

Pipeline:

Text → Tokens → IDs → Embeddings → Tensors

---

# **Predictive Modeling Analogy**

Traditional ML:

(X1, X2, …, Xk) → y

Text modeling:

(token_{i-2}, token_{i-1}) → token_i

Same structure:
Inputs → Model → Output.

---

# **Tokenization**

Splits text into:

- Word tokens
- Subwords (BPE)
- Characters

Models do **not** understand words—
they understand **token IDs**.

---

# **Example Sentence**

I love large language models.

Tokens:

- I
- love
- large
- language
- models
- .

---

# **Vocabulary → Token IDs**

Using larger IDs:

I → 101  
love → 587  
large → 233  
language → 902  
models → 744  
. → 999  

Encoded sentence:

[101, 587, 233, 902, 744, 999]

---

# **Context Window (Size = 2)**

Training samples:

[I, love] → large  
[love, large] → language  
[large, language] → models  
[language, models] → .  

In IDs:

[101, 587] → 233  
[587, 233] → 902  
[233, 902] → 744  
[902, 744] → 999  

---

# **Embedding Layer (dim = 3)**

Embeddings:

101 → [ 0.1, 0.2, 0.3 ]  
587 → [ -0.5, 0.1, 0.0 ]  
233 → [ 0.7, -0.2, 0.4 ]  
902 → [ 0.0, 0.3, 0.9 ]  
744 → [ 0.4, 0.4, 0.4 ]  
999 → [ -0.2, 0.0, 0.1 ]  

---

# **Input Tensor (Context = 2)**

Tokens = [101, 587]

Embeddings:

[ 0.1, 0.2, 0.3 ]  
[ -0.5, 0.1, 0.0 ]  

Tensor shape = 2 × 3

---

# **Training Examples (Tensor Form)**

[101, 587] →  
[[ 0.1, 0.2, 0.3 ],  
 [-0.5, 0.1, 0.0 ]]  
→ 233

[587, 233] →  
[[-0.5, 0.1, 0.0 ],  
 [ 0.7,-0.2, 0.4 ]]  
→ 902

[233, 902] →  
[[ 0.7,-0.2, 0.4 ],  
 [ 0.0, 0.3, 0.9 ]]  
→ 744

[902, 744] →  
[[ 0.0, 0.3, 0.9 ],  
 [ 0.4, 0.4, 0.4 ]]  
→ 999

---

# **Next Token Prediction**

Model learns:

Tensor (2×3) → Probability distribution

Example output:

P(large) = 0.72  
P(language) = 0.10  
P(models) = 0.08  

Prediction = argmax.

NLP concept → ML concept

Embeddings → Learned features  
Context window → Number of predictors
